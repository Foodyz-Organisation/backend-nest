================================================================================
FRONTEND EXPECTATIONS
================================================================================

The Android app expects messages with:

TYPE: 'shared_post'

META FIELDS:
  - sharedPostId (string): MongoDB _id of the post
  - sharedPostCaption (string): Post caption text
  - sharedPostImage (string): Relative path to image/thumbnail
    Example: "uploads/posts/1234567890.jpg"

The frontend will:
1. Detect type === 'shared_post'
2. Render Instagram-style image card
3. Display image from sharedPostImage
4. Show caption from sharedPostCaption
5. Navigate to PostDetailsScreen when clicked (using sharedPostId)

================================================================================
IMAGE PATH LOGIC
================================================================================

For Reels:
  sharedPostImage = post.thumbnailUrl || post.mediaUrls[0]

For Image Posts:
  sharedPostImage = post.mediaUrls[0]

Format: Relative path (e.g., "uploads/posts/image.jpg")
Note: Frontend automatically prepends BASE_URL
